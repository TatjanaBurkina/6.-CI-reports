# 📊 Allure Reporting & Testing Project (Интеграция Allure-отчетов и тестов)

Учебный проект, демонстрирующий генерацию наглядных графических отчетов с помощью **Allure Framework** на основе результатов выполнения тестов, а также организацию структуры проекта с использованием Maven и Python-скриптов.

---

## 📂 Структура проекта

Проект включает в себя следующие основные папки и файлы:

```text
├── Мэйвен/                 # Конфигурация и файлы сборщика Maven
├── __pycache__/            # Кеш компилятора Python (байт-код)
├── allure_report/          # Сгенерированные HTML-отчеты Allure
├── allure_results/         # Сырые результаты тестов (JSON/XML для генерации отчетов)
├── github/                 # Конфигурация CI/CD и workflows для GitHub Actions
└── test_mocking.py         # Скрипт с тестами и использованием мокинга в Python
